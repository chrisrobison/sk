# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

- Run image info script: `bash imginfo.sh`
- Generate JSON output: `bash imginfo.sh --json`
- Generate CSV output: `bash imginfo.sh --csv`

## Code Style Guidelines

### JavaScript
- Use modern ES6+ syntax
- Prefer const/let over var
- Use camelCase for variables and functions
- Maintain existing indentation (4 spaces)
- Place opening braces on the same line
- Document functions with clear comments
- Handle errors gracefully with try/catch

### HTML/CSS
- Follow HTML5 standards
- Use semantic HTML elements
- Maintain existing CSS structure (variables, selectors)
- Indent with 4 spaces
- Use BEM-like class naming where appropriate

### JSON
- Maintain consistent indentation (4 spaces)
- Use double quotes for keys and string values

### Shell Scripts
- Include proper error handling and validation
- Document usage with helpful comments
- Use consistent indentation (4 spaces)
- Include proper shebang lines
